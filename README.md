# J-ourney

**여행회의 (가칭)** · 페르소나 에이전트 기반 단체 여행 플래너

> 구성원별 AI 분신이 먼저 회의하여 전원이 만족하는 여행 일정을 제안하는 서비스

| 구분 | 내용 |
| --- | --- |
| 문서 유형 | 제품 요구사항 정의서 (PRD) |
| 기준 문서 | 여행회의 서비스 기획서 v1.1 (2026. 10. 12.) |
| 대상 이용자 | 친구·동아리 단위로 국내 여행을 계획하는 20~30대 |

## 1. 배경 및 문제 정의

- **P1. 구성원 간 취향 조율 실패**
  - 구성원별 선호(맛집·사진·예산·휴식) 상이에 따른 단체 대화방 내 결정 지연 및 대화 피로 누적
- **P2. 계획 업무의 1~2인 집중**
  - 응답자의 74%가 1~2명의 계획 전체 주도 경험, 82.5%가 단체 여행 준비 시 심리적 부담 응답
  - 담당자 부담 증가 및 나머지 구성원 의견 반영 미흡
- **P3. AI 추천의 근거 부족**
  - 여행 정보 탐색 시 AI 이용률 47% 대비 AI 추천 신뢰 응답은 22%에 불과함
  - 응답자의 68%가 AI보다 플랫폼 이용 기록을 우선 신뢰함
- **기존 서비스의 한계**
  - 트리브, MonkeyTravel, 네이버 AI 탭, ChatGPT 등은 개인 맞춤 추천 또는 단순 투표 기능에 한정됨
  - 구성원 간 취향을 대리 협상하여 합의안을 도출하는 기능은 부재함
- **시장 규모**
  - 연간 국내 여행 3억 900만 회, 연간 여행 지출 39.5조 원으로 역대 최대 규모 (2025 국민여행조사)

## 2. 제품 목표 및 성공 지표

- **제품 목표**
  - 일정 결정 기간 단축: 수일간의 단체 대화방 논의를 페르소나 생성(2분)과 AI 회의로 대체함
  - 계획 부담 분산: 구성원 전원의 선호를 각자의 AI가 대변하고 양보·확보 내역을 기록함
  - 추천 신뢰 확보: 모든 일정 항목에 구성원별 선정 사유 및 데이터 출처를 제시함
- **핵심 지표 (1단계)**
  - 회의 완료율, 합의안 수용률, 예약 전환율
  - 목표치: 월 활성 그룹 1만, 예약 전환율 20% (팀 가정값)

## 3. 범위

- **포함 범위 (1단계 · 출시 후 6개월)**
  - 친구·동아리 단위 그룹(최대 6명)의 국내 1~2박 여행
  - 흐름 A~D 전체 기능 및 숙소·체험 예약 제휴
- **제외 범위 (2단계 이후)**
  - 가족·커플·해외 여행 모드 및 항공 제휴
  - 단체 B2B 관리 기능, B2G 관광 코스, 페르소나 API

## 4. 기능 요구사항

- 탭 4개, 핵심 흐름 4개, 화면 16개로 구성함
  - **여행 탭**: 여행 목록 및 일정, 확정·예약·정산, 여행 평가
  - **회의 탭**: 회의 조건 설정 및 진행, 합의 결과 및 재협상, 여행 중 대안 투표
  - **페르소나 탭**: 성향 검사 및 페르소나 카드, 팀 궁합 및 갱신 이력
  - **전체 탭**: 알림 및 연결 계정, 개인정보 및 고객센터
- 핵심 흐름: **A. 페르소나 생성** → **B. AI 회의** → **C. 합의안·실행** → **D. 여행 중·이후**

## 5. 시스템 구성

- **역할 분담 원칙**: 판단은 LLM(페르소나 작성·구성원별 자료조사·일정안 평가), 계산·검증은 코드(일정 배치·경비·걸음 수·제약 검사·장소 실존 확인), 최종 결정은 사람(확정 투표)
- **구성원 에이전트**: LLM이 작성한 페르소나(여행 MBTI 유형, 관심사, 위반 불가 제약, 회의 말투)를 보유한 AI 분신
- **회의 진행자**: 라운드·발언 순서·투표 규칙 관리 및 합의 기준 충족 여부 판정
- **회의 절차**: AI 4명 동시 자료조사·후보 보드 → 일정안 작성(코드) → 페르소나 평가(LLM) → 요청 반영(코드)의 라운드 반복 → AI 합의안 → 사람 확정 투표
- **외부 도구**: 한국관광공사 TourAPI(전국 장소·영업시간·대표 메뉴·축제), 한국관광공사 연관 관광지·집중률 예측(인기도·혼잡도), 카카오 로컬·경로 API(실존 확인·이동 시간·지도 링크, LLM 입력에는 미사용), LLM API(특정 공급자에 묶이지 않도록 어댑터로 호출, 모델은 환경 변수로 교체)
- **산출물**: 합의 일정, 구성원별 예상 만족도, 선정 근거
- **기술 근거**: NTT 'AI Tour Meeting' 연구 (arXiv 2607.18806)
  - 참가자별 페르소나·목표·제약을 부여한 에이전트 간 대화·검색·제안·투표 반복 프레임워크
  - 취향 충돌 조건에서 합의율 94%, 평균 만족도 7.13점(10점 만점) 확인
  - 40억~90억 파라미터급 소형 모델의 회의 수행 가능성 확인
  - 연구용 시뮬레이션 결과로서 실제 집단과의 차이 가능성 존재 → 사람 최종 승인 단계 적용

## 6. 비기능 요구사항

| 구분 | 요구사항 |
| --- | --- |
| 신뢰성 | 공공 관광 데이터 목록에서만 장소를 고르고 카카오 장소 검색으로 실존을 확인하여 허위 장소 차단<br>인기도·혼잡도·영업시간은 공공 데이터 값을, 이동 시간은 카카오 경로 값을 쓰고 가격은 업종 기준 추정치로 표기하며, 모든 추천 항목에 선정 사유·데이터 출처·기준일과 카카오맵 링크 표기<br>외부 원본 데이터와 후기는 LLM에 넣지 않고 코드가 만든 점수·태그만 사용 (약관 준수) |
| 사람 최종 결정 | AI 산출물은 합의안(제안)으로 한정하고, 일정 확정·변경은 구성원 전원 찬성 투표로만 수행 |
| 지속 학습 | 여행 후 평가 결과를 페르소나에 반영하여 차기 회의 정확도 향상 |
| 응답 시간 | 페르소나 생성 2분 이내 완료<br>AI 회의·재협상 소요 시간은 화면 설계 예시값(회의 42초, 재협상 18초) 수준 목표 |
| 비용 | LLM은 판단·문장 생성에만 사용하여 여행 1건 약 18회 호출로 제한 (추정 비용 약 $0.012, 수십 원 이하), 페르소나·조사 결과 캐싱<br>공공 API·카카오 API의 무료 호출 한도 내 운영, LLM 장애 시 기본값·문장 틀로 대체 동작 |
| 개인정보 | 페르소나 데이터 수집 목적 고지 및 동의 절차 적용<br>외부 제공 시 개인 식별 정보 제외 및 통계화 |

## 7. 수익 모델

- **예약 제휴 수수료 (주수입)**: 합의 일정 내 숙소·체험·렌터카 예약의 제휴처 연결 및 예약액 기준 수수료 수취 (가정: 4%)
- **여행 패스 (보조)**: 여행 1건 단위 그룹 결제 (가정: 4,900원), 재협상·여행 중 재계획·자동 정산 기능 제공
