자동 시나리오

방장 생성 → 3명 참여(방장 포함 4명) → 5번째 참여 거절 → 상세 조회 → 오류 응답 확인을 차례로 실행함

    여행 만들기 (방장)

    POST /trips — 만든 사람이 방장이 되고 초대 코드와 토큰을 받음

    초대 코드로 참여

    GET /invites/{code} · POST /invites/{code}/join — 방장 포함 최대 4명

    이 브라우저의 구성원

    한 화면에서 여러 사람을 흉내 냄. 사람마다 받은 토큰으로 GET /trips/{tripId}를 호출함

    여행 상세

    GET /trips/{tripId}의 결과 (구성원·상태·회의 조건)

    위 구성원 목록에서 '상세 보기'를 누르면 표시됨

    요청·응답 기록

    최근 요청이 위에 표시됨. 줄을 누르면 본문을 펼침
